# Vaelora

Vaelora is a 2D, fixed-isometric, turn-based fantasy strategy game in preproduction. The first complete game targets Android, Windows, macOS, Linux, and Web, and begins with local matches against an AI opponent.

The game aims to pair approachable hex-map strategy with cities that grow, claim territory, build units or structures over time, and support a shared-but-asymmetric technology tree. Its setting is the continent of Vaelora, where rival civilizations rebuild after the decline of the old road-and-beacon network known as the Trama.

## Project status

Preproduction documentation is underway. No game implementation is included yet. Confirmed design rules and unresolved decisions are called out separately so the team can agree on the foundations before coding.

## Initial prototype

The first complete prototype focuses on two playable civilizations: the human Liga de Auren and the orc Clanes de Brasal. The other four planned civilizations are considered only after the prototype passes its final test battery. All prototype art is expected to be final quality; placeholder visuals are out of scope.
