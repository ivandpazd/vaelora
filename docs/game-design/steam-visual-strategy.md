# Vaelora — Steam and Commercial Visual Strategy v0.3

This document treats commercial presentation as a downstream use of the same accepted visual identity, not as a separate art style.

## 1. Current Steam asset matrix

As of the v0.3 production review, Steamworks documents these current required dimensions:

| Asset | Size |
|---|---:|
| Header capsule | 920×430 |
| Small capsule | 462×174 |
| Main capsule | 1232×706 |
| Vertical capsule | 748×896 |
| Library capsule | 600×900 |
| Library hero | 3840×1240 |
| Shortcut icon | 256×256 |
| App icon | 184×184 |
| Screenshots | minimum 1920×1080, 16:9 |

Before release production, verify these against current Steamworks templates again rather than treating this file as permanent platform policy.

## 2. Capsule rules

Base store capsules use game artwork + readable game name/logo; avoid review scores and unrelated calls to action. Library hero should be artwork-only; library logo is separate transparent logo artwork.

## 3. Vaelora commercial hook

A capsule should communicate three things instantly:

1. sculpted hex world;
2. luminous fantasy strategy;
3. civilization conflict/contrast.

Do not make the capsule primarily a generic character portrait that hides the board-game/diorama identity.

## 4. Screenshot strategy

Target initial screenshot set:

1. beautiful mixed-terrain board with both civilizations visible;
2. Auren developed city/road network;
3. Brasal frontier/work settlement;
4. coast/archipelago/naval scene;
5. tactical combat/selection state;
6. research/city-development UI over attractive board context.

Screenshots should come from actual game presentation. Debug overlays, placeholder UI and temporary art are not marketing candidates.

## 5. 320 px proxy

Every candidate screenshot is reduced to 320 px width during internal review. This approximates the rapid visual scan where large detail disappears.

At that size we still want:

- board structure;
- city focal point;
- strong land/water division;
- one or two readable unit/civilization cues;
- clean value grouping.

## 6. Key art

Key art may be richer than gameplay framing but should use the same materials, palette logic, faction language and world motifs. It should not create a darker/high-magic interpretation incompatible with the game.

## 7. Logo relationship

The logo should remain readable on busy organic backgrounds. Reserve visual quiet zones in capsule compositions rather than outlining the logo with excessive effects.

## 8. Store-art production gate

Do not invest heavily in final capsules until:

- representative game slice is accepted;
- board art identity is stable;
- Auren/Brasal silhouettes are stable;
- UI tone is established;
- at least one real gameplay screenshot looks commercially viable without paint-over.
