# Vaelora — VFX and Feedback Language v0.3

## 1. Purpose

VFX explains state changes and adds polish. It does not compensate for unreadable base art and it never becomes a continuous spectacle layer over a strategy board.

## 2. Visual character

Effects use:

- clean directional motion;
- route/node motifs where appropriate;
- short-lived particles/shapes;
- restrained luminous accents;
- readable value contrast;
- minimal smoke/noise.

Avoid generic magical glitter for non-magical civic/economic actions.

## 3. Event families

### Selection

Thin hex/route response + HUD confirmation. Persistent but calm.

### Valid action preview

Directional path/target language, readable without green hue alone.

### Invalid/rejected action

Short local response + contextual text; no camera shake required.

### Movement

Subtle step/path feedback; base unit animation carries most of the action.

### Melee impact

Brief directional contact shape/dust/metal cue.

### Ranged impact

Compact origin/target feedback; projectile traversal is optional per current gameplay presentation scope.

### City level-up

Short civic/structural emphasis around city; no giant magical explosion.

### Production complete

Small completion pulse tied to city/produced object.

### Research complete

Trama-node/link style completion feedback in UI and restrained world/HUD confirmation.

### Capture

Ownership transition that clearly changes faction state without obscuring the city.

### Victory

May be richer, but must still respect reduced-motion and UI readability.

## 4. Timing

Most gameplay feedback should complete quickly enough not to slow turn-based flow. Essential confirmation may persist in UI rather than extending particles.

## 5. Reduced motion

Every non-essential animated effect has a reduced/static alternative. Do not communicate success/failure exclusively through motion.

## 6. Camera effects

Camera shake is not a default language for Vaelora. If used later, it must be subtle, optional/reduced and never required for understanding combat.

## 7. Performance

Avoid large full-screen transparent particle fields. Effects should be local to the relevant tile/UI region whenever possible.
