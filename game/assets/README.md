# Game Assets — Vaelora v0.3 production contract

Store accepted final-quality game assets and licensed editable source files here. Placeholder visuals remain out of scope.

Generated Blender review candidates use `generated-v0.3.2-r2/` directories containing source `.blend`, raw 4× renders, manifests, final 2× PNGs, shadows, review sheets and QA evidence.

The approved [Terrain Visual Language v1](../../docs/game-design/TERRAIN_VISUAL_LANGUAGE_V1.md) establishes a terrain art-direction baseline at `v6.2-rc1`; its existing review renders are not a completed production export or Godot acceptance.

A generated file is not final merely because the generator succeeded. Lifecycle state must be explicit in its manifest/review.

Runtime asset decisions follow `docs/technical/godot-art-integration.md`.
